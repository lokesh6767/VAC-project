# AI Insight — User Stories

### Persona 1: Sarah, Computer Science Student
- **US-1.1:** As a CS student, I want to compare ChatGPT, Gemini, Copilot, and Claude on programming benchmarks so I know which assistant produces fewer syntax errors and handles debugging better.
- **US-1.2:** As a student on a budget, I want to clearly see which features are free vs. locked behind $20/month subscription tiers so I don't incur unnecessary costs.
- **US-1.3:** As a learner, I want to inspect repeatable benchmark tasks for concept explanation and math problem solving to evaluate how well each AI explains step-by-step logic.

### Persona 2: Alex, Senior Full-Stack Engineer
- **US-2.1:** As a software engineer, I want to see context window limits, API pricing per million tokens, and supported IDE/CLI integrations across all four competitors.
- **US-2.2:** As a developer, I want to run custom prompt benchmarks with expected criteria and evaluate the response on a 1–5 rubric for Accuracy, Relevance, Clarity, and Instruction-following.
- **US-2.3:** As an engineer concerned with enterprise safety, I want to verify whether model training is performed on input code and prompts by default for each competitor.

### Persona 3: Elena, Academic Researcher & Policy Analyst
- **US-3.1:** As a researcher, I want to view the Evidence Library to inspect original source URLs, publication dates, and last-verified timestamps for every vendor capability claim.
- **US-3.2:** As a policy analyst, I want to examine the SWOT analysis for each competitor to understand internal technical strengths and external regulatory or technological threats.
- **US-3.3:** As an author preparing a literature review, I want to export a comprehensive, structured PDF dossier with executive summary, methodology, comparison matrix, and full academic citations.

### Persona 4: Marcus, Enterprise Product Manager
- **US-4.1:** As a product manager, I want to use the Recommendation Engine to input my team's priorities (e.g. High Privacy, Coding capability, Low Cost) and receive an evidence-based recommendation with explicit rationale and trade-offs.
- **US-4.2:** As a decision maker, I want to save custom intelligence reports, reopen them, duplicate configurations, and share printable executive summaries with stakeholders.
- **US-4.3:** As a corporate buyer, I want clear distinctions between consumer web apps, team workspaces, and developer APIs to avoid buying the wrong tier.
