# AI Insight — Acceptance Criteria

### Module 1: Dashboard
- [ ] AC-1.1: Dashboard displays 4 core summary statistics: Tracked Competitors (4), Documented Capabilities, Benchmark Runs, and Saved Reports.
- [ ] AC-1.2: Evidence verification status bar shows the percentage and count of claims verified vs. pending review.
- [ ] AC-1.3: Overview cards for ChatGPT, Gemini, Copilot, and Claude display provider name, core model, top strength, and last verified date.
- [ ] AC-1.4: Capability radar/bar chart visually breaks down performance across reasoning, coding, math, research, multimodal, and ecosystem.
- [ ] AC-1.5: Quick action buttons immediately navigate to Comparison Workspace, Benchmark Lab, and Report Builder.

### Module 2: Competitor Explorer & Profiles
- [ ] AC-2.1: Individual profile pages exist for ChatGPT, Gemini, Microsoft Copilot, and Claude.
- [ ] AC-2.2: Each profile contains: Provider name, official website, documentation URL, product description, supported use cases, documented capabilities, modalities, models, pricing tiers, usage limits, privacy terms, advantages, and limitations.
- [ ] AC-2.3: Users can edit internal reviewer notes and toggle claim verification statuses (Verified, Needs review, Outdated, Disputed).
- [ ] AC-2.4: Consumer web applications are explicitly distinguished from developer API and enterprise workspace offerings.

### Module 3: Side-by-Side Comparison Workspace
- [ ] AC-3.1: Users can select any combination of 2, 3, or all 4 competitors to compare concurrently.
- [ ] AC-3.2: Comparison table displays rows grouped into clean categories (Reasoning, Coding, Math, Research, Multimodal, File Support, Context Window, Integrations, Pricing, Privacy).
- [ ] AC-3.3: "Show differences only" filter isolates rows where competitor capabilities diverge.
- [ ] AC-3.4: Category filters and capability text search work in real-time.
- [ ] AC-3.5: Every claim or capability cell has an inspectable badge opening verified evidence and source references.
- [ ] AC-3.6: Instant export button generates a clean PDF or print-ready comparison sheet.

### Module 4: Evidence Library & Source Management
- [ ] AC-4.1: Displays table of all evidence records with: Claim, Competitor, Category, Source URL, Publisher, Publication Date, Last Checked Date, Status, and Reviewer Notes.
- [ ] AC-4.2: Users can filter evidence by competitor, category, and verification status.
- [ ] AC-4.3: Users can add new claims with validated source URLs and edit existing verification notes.
- [ ] AC-4.4: Outdated or unverified sources are prominently highlighted with actionable review flags.
- [ ] AC-4.5: Absolutely zero fabricated citations or broken mockup URLs are presented as real facts.

### Module 5: Benchmark Lab
- [ ] AC-5.1: Ships with pre-configured repeatable benchmark tasks across 8 categories with prompts, expected criteria, and recorded outputs.
- [ ] AC-5.2: Users can create custom benchmark tasks with title, category, prompt, test files/inputs, and expected criteria.
- [ ] AC-5.3: Evaluation uses a strict 1–5 scoring rubric across 6 discrete dimensions: Accuracy, Relevance, Clarity, Instruction Following, Source Reliability, and Task Completion.
- [ ] AC-5.4: Aggregate scores apply explicit weighting and mathematically handle missing evaluations without fabricating zero scores.
- [ ] AC-5.5: Clear disclaimer informs users that benchmark scores represent the recorded sample set and not universal AI intelligence.

### Module 6: Strategic SWOT Analysis
- [ ] AC-6.1: Dedicated SWOT view for each competitor displaying Strengths, Weaknesses, Opportunities, and Threats in an accessible 4-quadrant grid.
- [ ] AC-6.2: Each SWOT point features a concise headline, explanatory analysis, evidence link, and confidence rating (High, Medium, Low).
- [ ] AC-6.3: Users can edit, add, or delete SWOT observations.
- [ ] AC-6.4: Cross-competitor SWOT comparison view allows side-by-side quadrant evaluation.

### Module 7: Task-Oriented Recommendation Engine
- [ ] AC-7.1: User selects from 6 primary tasks: Coding, Student Learning, Academic Research, Content Writing, Document Synthesis, Enterprise Office.
- [ ] AC-7.2: User adjusts importance weights for Accuracy, Cost, Ease of Use, Privacy, Integrations, Speed, and File Support.
- [ ] AC-7.3: Engine calculates fit score transparently, detailing primary reasons for selection, decisive criteria, trade-offs, and missing information.

### Module 8: Report Builder & Saved Reports
- [ ] AC-8.1: Report builder modal/page allows customizing report title, audience, author, selected competitors, and included sections.
- [ ] AC-8.2: Live dossier preview formats 10+ professional sections: Cover Page, Executive Summary, Scope & Methodology, Competitor Profiles, Comparison Matrix, Benchmarks, SWOT, Recommendations, Limitations, and References.
- [ ] AC-8.3: PDF/Print export triggers browser print-to-PDF or generates standalone PDF with immaculate page breaks and header/footer metadata.
- [ ] AC-8.4: Saved reports table allows reopening, duplicating, re-exporting, and deleting reports with persistent local storage.

### Module 9: Methodology, Settings & Security
- [ ] AC-9.1: Comprehensive methodology page documenting testing rubrics, calculation formulas, and evidence verification guidelines.
- [ ] AC-9.2: Privacy and security disclosures explaining API data handling, enterprise zero-retention policies, and user control.
- [ ] AC-9.3: Accessible (WCAG 2.2 AA compliant), responsive across desktop, tablet, and mobile, with keyboard navigability and high-contrast support.
